TripWeb 개인정보처리방침

Privacy Policy · 시행일 2026-11-02

TripWeb은 앱 소유자 한 사람이 자기 PC에서 실행하는 개인용 여행 플래너입니다. 이 방침은 TripWeb이 구글 계정 정보와 데이터를 어떻게 다루는지 설명합니다.

TripWeb is a personal trip planner that its owner runs on their own computer. This policy explains how it handles Google account data.

1. 사용하는 구글 권한

  • drive.file: TripWeb이 직접 만든 파일(여행 데이터 스프레드시트, "TripWeb" 폴더의 사진·오프라인 사본)만 만들고 고칩니다.
  • drive.readonly: 앱 소유자가 휴대폰으로 TripWeb 사진 폴더에 올린 사진을 읽어 와 일정에 붙이는 데에만 씁니다. TripWeb 폴더 밖의 파일은 열지 않습니다.

drive.file is used to create and update only the files TripWeb itself creates. drive.readonly is used only to read photos the owner uploads into TripWeb's own photo folders.

2. 저장하는 곳

  • 여행 데이터와 사진은 앱 소유자의 PC와 앱 소유자 본인의 구글 드라이브에만 저장됩니다.
  • 구글 로그인 토큰은 앱 소유자의 PC에만 저장되며, 연결을 끊으면 지우고 구글 쪽 권한도 취소합니다.

Data stays on the owner's computer and in the owner's own Google Drive. OAuth tokens are stored only on the owner's computer and are deleted and revoked on disconnect.

3. 공유·판매하지 않음

TripWeb은 구글에서 받은 데이터를 다른 사람이나 회사에 보내거나 팔지 않고, 광고나 분석에 쓰지 않습니다. 운영 서버가 따로 없습니다.

TripWeb does not transfer, sell, or use Google user data for advertising or analytics. There is no separate hosted server.

TripWeb's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 사용자

TripWeb은 앱 소유자 본인만 사용합니다. 다른 사람의 개인정보를 모으지 않습니다.

5. 삭제

TripWeb 화면의 "연결 끊기" 또는 구글 계정 설정의 "타사 앱 및 서비스"에서 언제든 권한을 취소할 수 있습니다. 드라이브의 TripWeb 폴더를 지우면 사본도 사라집니다.

6. 문의

이 앱의 구글 동의 화면에 적힌 지원 이메일로 문의할 수 있습니다.
